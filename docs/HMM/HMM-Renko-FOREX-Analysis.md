- **Pip Calibration**: Always set brick sizes in pip-equivalent units, not raw price. Use 10-50 pip bricks for standard pairs and 20-80 pip bricks for JPY pairs.
- **Spread Awareness**: FOREX spreads are typically 0.5-3 pips for majors, 3-10 pips for crosses. The 1bps spread_bps used here is conservative; real spreads may be wider.

- **Warmup**: Always warm up the Renko pipeline with at least 200 bars of data before trading.
- **Kelly Sizing**: Use half-Kelly (fraction=0.5) for position sizing. Full-Kelly is too aggressive for FOREX's leverage.
- **Re-optimization**: FOREX regime shifts happen quarterly. Re-optimize every 2-4 weeks.
